# MojPrijevoz - ride-sharing platforma

## Upute za pokretanje aplikacije
 - Raspakovati `MojPrijevoz.WebApi-secrets.zip` u `MojPrijevoz/MojPrijevoz/MojPrijevoz.WebApi` koristeći šifru navedenu prilikom predaje rada.
 - Unutar istog foldera pokrenuti komandu `docker compose up --build`
 - **Ukoliko je potrebno** za frontend stranu, raspakovati `config-secrets.zip` na isto mjeste gdje se i nalaze unutar moj_prijevoz/moj_prijevoz_admin foldera.
